# RTX Video Upscale Extension for SwarmUI

An extension for [SwarmUI](https://github.com/mcmonkeyprojects/SwarmUI) that enables NVIDIA RTX Video Super Resolution (VSR) and tensor-accelerated upscaling for video generation workflows and history media view.

## Features
- Hardware-accelerated upscaling utilizing NVIDIA RTX tensor cores.
- Direct integration with video post-processing pipelines.
- Interactive action button in the SwarmUI history view for upscaling generated clips.
